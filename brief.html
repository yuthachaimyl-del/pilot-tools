2 · Weather ที่ ETA ±1 ชม.

แอปดึง TAF และ METAR ของ DEP / ARR / ALT จาก aviationweather.gov ผ่าน Parallel Search ให้อัตโนมัติ แล้วหา TEMPO / PROB / BECMG / FM ที่ทับช่วง ±1 ชม. ของแต่ละขา ถ้าดึงไม่ได้ ให้เปิดลิงก์แล้วคัดลอกข้อความมาวางแทน

3 · NOTAM

ค้น NOTAM (FAA) ↗
📋 วิธี copy NOTAM จากแอป AeroWeather มาวาง (แม่นยำกว่า) ›
✓ วิธีนี้แม่นยำกว่า · ได้ข้อความ NOTAM ตัวจริงครบทุกตัวอักษร ไม่มีขั้นตอนอ่านจากรูป จึงไม่มีโอกาสอ่านเลข RWY / TWY / stand / เวลา / วันที่ผิด และไม่ตกหล่นบรรทัดที่ถูกตัดขอบจอ · ดีกว่าแคปรูป และครบกว่าการดึงอัตโนมัติ ถ้าแหล่ง FAA ยังไม่มี NOTAM ใหม่ของสนามบินนั้น
  1. เปิดแอป AeroWeather → แตะสนามบิน DEP (เช่น VTBS) → แท็บ NOTAM ด้านล่าง
  2. แตะปุ่ม ⋯ มุมขวาบน → เลือก Copy (คัดลอก NOTAM ทั้งหมดของสนามบินนั้น)
  3. กลับมาที่ CoolCrew → แตะค้างในช่อง วาง NOTAM ด้านบน → Paste
  4. ทำซ้ำกับสนามบิน ARR และ ALT · วางต่อท้ายในช่องเดิม (ขึ้นบรรทัดใหม่ก่อนวาง)
  5. กด สรุป NOTAM ตามช่วงเวลาบิน · รอจนเสร็จก่อนสลับไปแอปอื่น

5 · เครื่องขาเข้า

เปิด FR24 ของไฟลท์แรก ดูว่าเครื่องลำนี้กำลังบินขาไหนอยู่ และจะถึงกี่โมง ถ้าเครื่องเข้าช้า turnaround ขาแรกจะถูกบีบ

ตารางเดือน

Early start 05:00–05:59 Late finish 23:00–01:59 Night duty 02:00–04:59 Report นอกบ้าน

ตั้งปลุกในปฏิทินมือถือ

สร้างไฟล์ปฏิทิน (.ics) ของ duty ที่ยังไม่ถึง ตั้งแต่ report ถึง release พร้อมแจ้งเตือน งดแอลกอฮอล์ ปลุก ปลุกซ้ำ และออกจากบ้าน แตะดาวน์โหลดแล้วเปิดไฟล์ เครื่องจะถามว่าจะเพิ่มเข้าปฏิทินไหน

การแจ้งเตือนของปฏิทินเป็น notification ไม่ใช่นาฬิกาปลุกที่ดังต่อเนื่อง สำหรับ early start ควรตั้งนาฬิกาปลุกของเครื่องไว้อีกชั้น

วิธีเพิ่มเข้าปฏิทิน
  1. iPhone: แตะดาวน์โหลด แล้วแตะไฟล์ที่ได้ เลือก Add All และเลือกปฏิทินที่ต้องการ
  2. Android / Google Calendar: เปิดไฟล์ด้วยแอป Calendar หรือเข้า calendar.google.com บนคอม → Settings → Import
  3. ถ้า roster เปลี่ยน ให้ดาวน์โหลดใหม่ duty เดิมใช้รหัสเดิม ปฏิทินส่วนใหญ่จะอัปเดตทับ ถ้าขึ้นซ้ำให้ลบอันเก่าออก
